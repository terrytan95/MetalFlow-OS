# MetalFlow Foundry Design System
Source: https://github.com/jimliu/baoyu-design. Product context: metal distribution and renovation operations. Original identity informed by the supplied Linear/Stripe/Vercel references; no copied product UI.
## Content fundamentals
Sentence case, direct action labels, ISO currency codes, explicit uncertainty. No invented production metrics.
## Visual foundations
Warm neutral canvas, forest teal actions, 7px radii, 1px borders, no decorative gradients or shadows. System fonts with Chinese fallback. Spacing uses 8px rhythm. Tables prioritize identifiers, parties, status and amounts. Reduced motion supported. Light and dark themes share semantic tokens.
## Iconography
Production uses Lucide line icons. No emoji. No decorative images in operational views.
## Components
App shell, form fields, buttons, status badges, metric cards, tables, drawers and accessible dialogs. Native semantic controls in prototypes; Radix primitives and shadcn patterns in production.
